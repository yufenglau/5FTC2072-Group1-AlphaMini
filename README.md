# Team Project G1
The AlphaMini Sign Translator is an assistive autonomous system designed to translate human sign language/gestures into vocalized speech. By leveraging computer vision and the AlphaMini robot's physical capabilities, this project aims to bridge the communication gap for individuals who rely on sign language.
